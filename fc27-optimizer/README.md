# FC 27 Optimizer — стабильные FPS и минимальный пинг в EA SPORTS FC 27

Набор скриптов для Windows 10/11 и пошаговая инструкция. Всё, что меняют скрипты, сохраняется
в резервную копию и откатывается одним файлом.

| Файл | Что делает | Права администратора |
|---|---|---|
| `1_Check.bat` | Диагностика ПК и интернета: пинг, джиттер, потери, bufferbloat, Wi-Fi/кабель, VPN, фоновые программы. **Ничего не меняет.** Отчёт сохраняется на рабочий стол. | нет |
| `2_Optimize.bat` | Применяет оптимизации Windows, сети и питания под FC 27. | да |
| `3_Restore.bat` | Возвращает всё как было до `2_Optimize.bat`. | да |

---

## Сначала честно про пинг

Пинг складывается из трёх частей:

1. **Расстояние до сервера EA** — сервер выбирает игра, никакой скрипт его не «приблизит».
2. **Маршрут провайдера** — меняется только сменой провайдера/тарифа или VPN-маршрутизаторами (см. FAQ).
3. **Ваша домашняя сеть и ПК** — вот тут можно выиграть больше всего.

В FC сильнее всего мешает не высокий пинг, а **нестабильный**: скачки, джиттер и потери пакетов.
Из-за них управление становится «ватным», игроки «телепортируются», а удары запаздывают.
Именно это и лечит набор.

**Что даёт эффект — по убыванию:**

1. 🔌 **Кабель вместо Wi-Fi.** Ничто другое не сравнится.
2. 📶 **SQM/QoS на роутере** — убирает лаги, когда кто-то дома качает или смотрит видео (bufferbloat).
3. 🚫 **Без VPN, торрентов, облачной синхронизации и загрузок** во время матча.
4. ⚡ **Сетевая карта без энергосбережения** и правильный план питания (делает `2_Optimize.bat`).
5. 🎮 **Стабильный фреймрейт без просадок** (драйвер, настройки игры, XMP/EXPO).

## Быстрый старт

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте. Папка `fc27-optimizer` — всё, что нужно.
2. Запустите **`1_Check.bat`** — это «до». Отчёт появится на рабочем столе (`FC27-check-….txt`).
   В конце скрипт попросит запустить тест скорости в браузере — так он измерит bufferbloat.
3. Запустите **`2_Optimize.bat`** и нажмите «Да» в окне UAC.
   Хотите сначала посмотреть, что изменится? Откройте консоль в папке и выполните `2_Optimize.bat -DryRun`.
4. **Перезагрузите компьютер.**
5. Пройдите ручные шаги ниже — они дают не меньше, чем скрипт.
6. Снова запустите **`1_Check.bat`** и сравните с первым отчётом.

> Если Windows показывает «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**.
> Это обычное предупреждение для любых скачанных `.bat`. Скрипты — открытый текст, их можно прочитать в папке `scripts`.

## Что делает `2_Optimize.bat`

Меняются только стандартные настройки Windows — то же самое можно сделать руками через «Параметры»,
Диспетчер устройств и реестр. Файлы игры, античит и драйверы не трогаются.

| Настройка | Зачем | Эффект |
|---|---|---|
| Точка восстановления Windows | Страховка | — |
| План питания **«FC27 Max Performance»** (на основе «Максимальной производительности») | CPU не сбрасывает частоты и не паркует ядра → меньше микрофризов | заметный |
| В плане: USB не засыпает | Геймпад не отваливается и не «подвисает» | заметный, если были отвалы |
| В плане: PCIe и Wi-Fi без энергосбережения | Сетевая карта не уходит в сон между пакетами → меньше скачков пинга | заметный на Wi-Fi |
| Сетевой адаптер: выкл. Energy Efficient Ethernet / Green Ethernet / ULP / Flow Control / Interrupt Moderation | Убирает задержки «пробуждения» и пакетирования на сетевой карте | небольшой–заметный |
| Адаптер: снят флажок «Разрешить отключение этого устройства для экономии энергии» | Windows не «усыпляет» сетевую карту | небольшой–заметный |
| Wi-Fi (Intel): минимальная агрессивность роуминга | Меньше фоновых сканирований эфира, которые дают скачки пинга раз в минуту | заметный на Wi-Fi |
| Сетевые пакеты игры помечаются как приоритетные (DSCP 46) | Роутер с QoS/WMM пропускает их первыми; в Wi-Fi они идут в самую быструю очередь | ситуативный: зависит от роутера |
| Windows Update не раздаёт обновления другим ПК | Отдача обновлений забивает исходящий канал → лаги | заметный, когда раздача шла |
| Игровой режим Windows включён | Windows меньше отвлекается на фоновые задачи | небольшой |
| Запись Xbox Game Bar (Game DVR) выключена | Не пишет видео в фоне, не тратит GPU и диск | заметный, если запись была включена |
| Кнопка Xbox на геймпаде не открывает Game Bar | Не вылетит оверлей посреди атаки | удобство |
| Игра запускается с высоким приоритетом CPU | Фоновые программы меньше отнимают процессор | небольшой–заметный на слабых CPU |
| Игра всегда на дискретной видеокарте | На ноутбуках не запустится на встроенной графике | огромный на ноутбуках с двумя GPU |
| Планировщик мультимедиа (MMCSS): приоритет игр, без ограничения сети | Классический «игровой» профиль Windows | небольшой |
| TCP без задержки подтверждений (Nagle off) | Касается только TCP-трафика | небольшой |

Резервная копия исходных значений — `C:\ProgramData\FC27-Optimizer\backup.json`.
Повторный запуск безопасен: в копии остаются самые первые, «родные» значения.

**Параметры запуска** (из консоли, например `2_Optimize.bat -DryRun`):

| Параметр | Что делает |
|---|---|
| `-DryRun` | Только показать план, ничего не менять |
| `-GamePath "D:\Games\EA SPORTS FC 27"` | Путь к игре, если автопоиск не нашёл (можно папку или сам `FC27.exe`) |
| `-ExeName FC26.exe` | Для другой части серии |
| `-SkipPowerPlan` | Не трогать план питания (например, на ноутбуке, который играет от батареи) |
| `-SkipNetwork` | Не трогать сетевой адаптер |
| `-SkipGamePriority` | Не повышать приоритет процесса игры |
| `-SkipRestorePoint` | Не создавать точку восстановления |

## Ручные шаги

### 1. Интернет и роутер — самое важное для пинга

**Кабель.** Если протянуть кабель невозможно:
- подключайтесь к сети **5 ГГц** (или 6 ГГц), а не 2,4 ГГц;
- уберите стены между ПК и роутером, поставьте ПК ближе;
- Wi-Fi-адаптер — встроенный PCIe или хороший USB в порт на задней панели, а не «свисток» в передний порт;
- в настройках роутера выберите свободный канал; mesh-системы лучше соединять между собой кабелем.

**Bufferbloat → SQM/QoS.** Если `1_Check.bat` поставил оценку B или ниже — это ваша главная причина лагов,
когда дома кто-то качает, смотрит 4K или идёт обновление. Включите «умную очередь» на роутере и ограничьте
скорость на **85–90%** от реальной (измерьте тестом скорости):

| Роутер | Где включить |
|---|---|
| Keenetic | Компонент **IntelliQoS** → включить, задать скорость; игровой ПК — в приоритет |
| ASUS | Adaptive QoS → **QoS** → тип «Adaptive» или «Traditional», задать скорости; ПК — высокий приоритет |
| TP-Link | Дополнительные настройки → **QoS** → задать скорости, ПК — высокий приоритет |
| MikroTik (RouterOS 7) | Queues: simple queue / queue tree с типом **cake** или **fq-codel** на WAN |
| OpenWrt | Пакет `luci-app-sqm`, очередь **cake**, скрипт `piece_of_cake.qos` |
| Роутер провайдера | Часто QoS нет. Попросите у провайдера режим «мост» и поставьте свой роутер |

**Остальное:**
- **UPnP — включить** на роутере: игре проще установить соединение (открытый NAT).
  Если UPnP нет — пробросьте порты по списку EA для EA SPORTS FC на [help.ea.com](https://help.ea.com).
- **VPN выключать на время матча** — он почти всегда добавляет пинг. Если VPN нужен постоянно — используйте
  раздельное туннелирование и исключите из него `FC27.exe` и EA app.
- **Во время игры ничего не качать:** Steam/EA app/Epic, торренты, OneDrive/Яндекс Диск/Google Drive, обновления Windows
  (Параметры → Центр обновления → «Приостановить» на вечер игры).
- Скорость тарифа почти не влияет на пинг — игре хватает 10–20 Мбит/с. Важны стабильность и отсутствие потерь.
- Если по **кабелю** `1_Check.bat` показывает потери или высокий джиттер до интернета, а до роутера всё чисто —
  это провайдер. Отправьте ему отчёт с рабочего стола.

### 2. Видеокарта

- Поставьте **свежий драйвер** с сайта производителя (для NVIDIA/AMD — «чистая установка»).
- **Частота экрана:** Параметры → Система → Дисплей → Расширенные параметры дисплея → максимальная частота.
  Нередко монитор 144 Гц годами работает на 60 Гц.
- **HAGS** (Параметры → Система → Дисплей → Графика → «Планирование GPU с аппаратным ускорением»):
  на NVIDIA GTX 10xx и новее / AMD RX 5000 и новее обычно лучше **включить**. Если появились фризы — выключите.

**NVIDIA** — Панель управления NVIDIA → Управление параметрами 3D → Программные настройки → FC 27:

| Параметр | Значение |
|---|---|
| Режим низкой задержки | **Ультра**. Работает только для DX11; если игра на DX12 — эффекта не будет, но и вреда тоже. Если в игре есть NVIDIA Reflex — включите его в игре |
| Режим управления электропитанием | **Предпочтителен режим максимальной производительности** |
| Фильтрация текстур — качество | **Высокая производительность** |
| Размер кэша шейдеров (глобально) | **10 ГБ** или **Без ограничений** |

В приложении NVIDIA (или GeForce Experience) выключите оверлей и «Мгновенный повтор», если не пользуетесь.

**AMD** — Adrenalin → Игры → FC 27: **Radeon Anti-Lag — вкл**, Radeon Chill — выкл, Radeon Boost — выкл,
Enhanced Sync — выкл. Запись и оверлей — выкл, если не нужны.

### 3. Настройки FC 27

В прошлых частях FC геймплей на ПК был ограничен 60 кадрами. Значит, цель — не «максимум FPS», а **ровные кадры без
единой просадки** и минимальная задержка ввода.

- **Режим экрана:** полноэкранный (Fullscreen). Разрешение — родное для монитора.
- **Вертикальная синхронизация:** выкл (меньше задержка). Если мешают разрывы картинки и монитор с G-Sync/FreeSync —
  включите G-Sync/FreeSync + V-Sync в панели драйвера.
- **Ограничение кадров** — на уровне, который ПК держит стабильно в самых тяжёлых сценах.
- **Если есть просадки** — снижайте по порядку: качество рендеринга → толпа/зрители → трава → ткани → тени → сглаживание.
  Если в игре есть DLSS/FSR/XeSS — режим «Качество».
- **Размытие в движении** (если есть в настройках): выкл.

### 4. Windows и программы

- **Автозагрузка:** Диспетчер задач → Автозагрузка → отключите всё лишнее.
- **Оверлеи:** Discord (Настройки → Оверлей в игре → выкл), Steam (Свойства игры → «Оверлей Steam в игре» → выкл),
  EA app (Настройки → Приложение → внутриигровой оверлей) — оставьте один, который нужен.
- **Игра — на SSD.** На HDD будут подгрузки и подтормаживания.
- **Обновите Windows** и драйвер чипсета материнской платы.
- **Антивирус не выключайте** — это почти не даёт FPS, а риски реальные.
- *Необязательно:* «Целостность памяти» (Безопасность Windows → Безопасность устройства → Изоляция ядра) может стоить
  несколько процентов FPS на старых процессорах. Отключение снижает защиту системы — на современных ПК не рекомендуем.

### 5. Железо и BIOS

- **XMP / EXPO — включить в BIOS.** Без него память работает на базовой частоте (DDR4-2133/2400, DDR5-4800),
  а это на многих ПК заметно меньше FPS и больше фризов, особенно на Ryzen. `1_Check.bat` подскажет, если частота базовая.
- **Две планки памяти вместо одной** (двухканальный режим).
- **Resizable BAR / Smart Access Memory** — включить в BIOS (если видеокарта поддерживает).
- **Ноутбук:** играть от сети; режим «Производительность/Турбо» в фирменной утилите (Armoury Crate, Lenovo Vantage,
  MSI Center, OMEN Gaming Hub); если есть MUX-переключатель — режим «только дискретная видеокарта»; подставка с охлаждением.
- **Температуры:** почистите ПК от пыли. Перегрев = сброс частот = фризы.

## Как читать отчёт `1_Check.bat`

| Показатель | Хорошо | Плохо |
|---|---|---|
| Пинг до роутера | 1–2 мс по кабелю, до 5 мс по Wi-Fi | больше 5 мс или скачки до 30+ мс |
| Потери до роутера | 0% | любые |
| Потери до интернета | 0% | больше 1% |
| Джиттер до интернета | до 3–5 мс | больше 8 мс |
| Bufferbloat (рост пинга под нагрузкой) | A+ / A (меньше 30 мс) | C и ниже (больше 60 мс) |

- Всё плохо **уже до роутера** → проблема дома: Wi-Fi, кабель, роутер.
- До роутера чисто, **до интернета** потери/джиттер → роутер или провайдер.
- В покое всё хорошо, а **под нагрузкой** пинг взлетает → bufferbloat, включите SQM/QoS.

Пинг до `1.1.1.1` и `8.8.8.8` — ориентир «до ближайшего интернета». До серверов EA он будет выше:
это зависит от того, в каком дата-центре проходит матч.

## Откат

- **`3_Restore.bat`** — возвращает все значения из резервной копии, включает прежний план питания и удаляет
  созданные политики. После отката перезагрузите ПК.
- Крайний вариант — **Панель управления → Восстановление → Запуск восстановления системы** → точка «FC27 Optimizer».

## FAQ

**Не забанят ли?** Скрипты не изменяют файлы игры, не подключаются к её процессу и не взаимодействуют с античитом.
Они меняют только стандартные настройки Windows, сетевой карты и питания.

**Помогут ли ExitLag, GearUP, NoPing и подобные?** Иногда — если у провайдера плохой маршрут до серверов EA.
Часто — нет. Если хотите попробовать, сравнивайте пинг прямо в игре на пробном периоде, а не по рекламе.

**Смена DNS снизит пинг?** Нет. DNS влияет только на скорость открытия сайтов и подключения к сервисам,
но не на пинг в матче.

**Запускаю под обычным пользователем и ввожу пароль администратора — работает?** Системные настройки применятся,
а пользовательские (игровой режим, Game Bar, выбор видеокарты) попадут в профиль администратора.
Лучше запускать из учётной записи, в которой вы играете и которая сама является администратором.

**У меня FC 26 / другая часть.** Запустите из консоли: `2_Optimize.bat -ExeName FC26.exe` (и так же для `1_Check.bat`).
