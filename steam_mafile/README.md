# steam_mafile — автопривязка Steam Guard и создание .maFile

Софт выполняет официальный мобильный flow Steam (тот же, что делает мобильное
приложение Steam и Steam Desktop Authenticator): вход по логину и паролю,
подтверждение кодом Steam Guard из письма, привязка мобильного
аутентификатора и сохранение готового `.maFile` в формате SDA.

> Только для аккаунтов, которыми вы владеете. Нужны реальный пароль и доступ
> к почте/телефону аккаунта. Инструмент ничего не обходит — он лишь
> автоматизирует штатные шаги привязки Steam Guard.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python -m steam_mafile --out maFiles
```

Дальше по шагам (по одному аккаунту, интерактивно):

1. Ввести логин и пароль (пароль не отображается при вводе).
2. Ввести код Steam Guard из письма на почте (если у аккаунта включён
   email-Guard).
3. Софт привязывает аутентификатор и **сразу показывает revocation code**
   (`R#####`) — сохраните его, без него нельзя отвязать аутентификатор.
4. Ввести код активации из SMS (Steam присылает его на привязанный телефон).
5. Готовый `.maFile` сохраняется в каталог `--out` (по умолчанию `./maFiles`),
   права файла `600` (только владельцу).

Черновик `.maFile` сохраняется ещё до ввода кода активации — секреты и
revocation code не потеряются, даже если код активации введён с ошибкой.

## Требования Steam

- К аккаунту должен быть привязан **номер телефона** — иначе Steam не даёт
  привязать мобильный аутентификатор (софт сообщит об этом).
- Если на аккаунте уже есть мобильный аутентификатор, повторная привязка
  невозможна без его отвязки (нужен текущий revocation code).

## Формат .maFile

JSON, совместимый со Steam Desktop Authenticator: `shared_secret`,
`identity_secret`, `revocation_code`, `serial_number`, `uri`, `device_id`,
`token_gid`, `secret_1` и блок `Session` (SteamID, AccessToken, RefreshToken).

## Структура

| Файл | Назначение |
|------|-----------|
| `crypto.py` | RSA-шифрование пароля, генерация TOTP-кода Steam Guard, device id |
| `protobuf.py` | минимальный кодек protobuf для запросов к WebAPI |
| `client.py` | клиент flow: RSA-ключ → вход → код с почты → токены → привязка |
| `mafile.py` | сборка и сохранение `.maFile` |
| `cli.py` | интерактивный CLI |

## Тесты

```bash
python -m pytest -q
```

Тесты офлайн: криптография (сверенные TOTP-векторы, roundtrip RSA/PKCS#1 v1.5),
кодек protobuf, конечный автомат клиента через подменённый транспорт и запись
`.maFile`. Сеть для тестов не нужна.
